## 四项补全复验（GAPS-4）

仅操作 DISPLAY=:17 上这次测试实例；启动/重启方法仍见前文与 `linux-test/launch-gui.py`、`stop-gui.py`。登录资料仅在 `/workspace/NextShell-notes/linux-test/private/login.json`（600）中读取，不粘贴到报告/截图。

### 1. Ctrl+Tab MRU
- 打开至少三个 SSH 或本地终端标签 A/B/C，用鼠标依次激活 A、C、B。
- B 中按住 Ctrl，按 Tab：上方出现最近使用条，高亮 C；**当前实际终端仍然是 B**。继续按 Tab 高亮 A，Ctrl+Shift+Tab 回到 C；松 Ctrl 才激活 C。
- 再按 Ctrl+Tab 应优先预览 B（不是物理相邻标签）。循环中 Ctrl+↑/↓ 可选上一/下一项。
- 循环中 Esc、切换到其他窗口应取消，不应激活预览项；鼠标点击另一个标签取消旧循环。关闭/重排标签后重试，无崩溃或跳到已关闭 ID。

### 2. SFTP 多选 / 远端剪贴板 / 目录复制
- 在本机测试目标的**新建临时目录**放两个文本文件和一个含子目录的目录；不要用真实资料。
- 文件页刷新。单击选一项，Ctrl+单击增减选项，Shift+单击选连续范围，Ctrl+A 全选；目录用**双击或 Enter** 打开（不再单击立即进入，以便多选）。
- 选两项点“复制所选”或 Ctrl+C；进入另一临时目录后点“粘贴到当前目录”/Ctrl+V。传输页应出现每项一个任务，完成后返回文件页**刷新目录**查看；原文件仍在。
- 同一会话选文件/目录“剪切所选”/Ctrl+X，再到另一目录粘贴；队列完成后源消失、目标完整。失败/取消不能删除源。不同会话只在地址、账户、代理及非空已验证 pin 全匹配时允许剪切。
- 复制目录后切到另一个 SSH 标签，刷新目标目录并粘贴；核对子目录和中文文件内容。真实不同服务器路径已由两套 in-process SSH/SFTP 服务验证；人工不要连外部主机。
- 目标重名应失败，不能偷偷覆盖/合并；符号链接/特殊文件拒绝，不越过它们继续复制。剪贴板不会因为失败清空；剪切成功后再次粘贴应安全报源不存在。目录复制上限 10000 项/64 层。

### 3. 多文档编辑
- 在文件页依次编辑 one.txt、two.txt；应出现两个原生文档标签。编辑 one.txt 后出现 ●；切换两次，修改、撤销记录、选区和滚动位置仍在。
- 不同 SSH 会话打开同路径文件应是不同文档；同会话同路径重复打开不能增加重复标签。
- 点保存，远端内容更新、● 消失；保存请求发出后继续输入，新字不能被返回的旧保存响应覆盖。保存其他文档不能抢当前文档焦点。
- 点脏文档的 ×：“取消关闭”保留；“不保存关闭”丢弃且只关该文档；“保存并保留文档”保存但明确保持打开（成功后再关）。制造远端修改时保存应报哈希冲突，草稿仍在。
- 断开会话后文档仍可保留草稿，保存失败不能消失；应用退出时应提示未保存文档数。最多 32 文档；未保存草稿不跨进程恢复。

### 4. 监控历史曲线
- SSH 标签 → 监控 → 勾选“每 2 秒刷新” → “历史曲线”；等待至少 3 次采样。
- CPU、内存/Swap、网卡收发（KiB/s）、选定挂载点容量占用应绘线；可切网卡和挂载点，点上悬停可看时间/数值；没有 Swap 显示 —，首个 CPU/网卡样本缺 delta 不应造 0。
- 超过 50 点会滚动保留最近 50 点；切换 SSH 会话不能混线。停止采样超过 10 秒再刷新，缺口应断线。
- 磁盘曲线是容量百分比，不是读写 I/O；历史仅内存保留，关闭会话/重启清空，最多缓存 32 会话。
