## A 连接/分组（重点）
1. 右击左侧测试连接：应有连接、编辑、重命名、复制地址、复制配置、导出、复制到云页、移入回收站。复制地址应为user@host:port，IPv6带方括号。
2. 重命名“本机测试 SSH（密码）”为测试名字；确认后树同步更新，密码仍可连接。改完恢复原名。
3. 连接页编辑tags和备注保存；侧栏搜索标签/备注/目录名能找到连接。**管理表尚无完整独立筛选器**。
4. 勾选两条连接，右击选区内应显示批量菜单；右击未选中行只作用该行，不误删除旧选区。导出菜单只预选对应行，不直接导出文件。
5. 右键移入回收站出现可恢复确认；取消不得改DB。确认后可从回收站恢复。**编辑表单原来的“移入回收站”仍直接软删除**。
6. 右击目录：新建子目录、编辑、递归选中用于批绑、删除空目录。非空/被引用目录删除应报错，不递归删除连接。

## B 标签/终端（重点）
1. 打开两个本机终端；右击标签检查管理/重命名/恢复自动标题/复制/重连/清屏/清缓冲/关闭。
2. 点终端正文获得焦点，测Ctrl+1、Ctrl+9、Ctrl+PageUp/Down、Ctrl+Shift+[或]、Ctrl+Shift+D、Ctrl+Shift+W。仅终端焦点有效；Ctrl+Tab MRU尚未做。
3. 输入框内Ctrl+1不应切标签；裸Ctrl+W必须发给shell（删前词），不能关标签。发布版Ctrl+Shift+C/V复制粘贴，不能弹Elements。
4. 终端运行`printf '\033]0;OSC-title-A\007'`，标签随之变化；手工重命名后再发OSC标题不得覆盖。右键“恢复自动标题”应恢复OSC显示。
5. 设置关闭“允许OSC标题更新”，再发OSC标题：不更新；重新开启后恢复。人工名称仍最高优先级。
6. 快速输入长英文和中文，观察是否延迟/丢字/乱序。**之前原生问题仍UNVERIFIED；离屏200字全正确不能证明原生已修好**。只操作这个测试实例。

## C 设置/持久化（重点）
1. 设置→终端：字段应由官方Form对齐，字号14、行高1.2、跟随外观；默认OSC读写均关闭，链接确认开启。
2. 改字号18、行高1.4、Dracula并保存：现有终端字体/颜色立即变化；切亮/暗主题无破版。非法字号99、颜色red、NaN行高不得保存。
3. 光标bar、不闪烁、缓冲20 MiB：保存后**新开/重连**才生效；不应该偷偷断开现有连接。缓冲单位是MiB，不是行数。
4. 本地shell填`/bin/bash`（不能附加参数），保存后新开本地终端；空值回系统默认。
5. 全局keepalive 15秒→20秒，新建继承连接使用20；连接显式关闭优先；重连时应重新解析全局继承。
6. 默认下载目录改为已存在的`/workspace/NextShell-notes/v1-parity/downloads`；默认外部编辑程序可填用户自己已有程序。路径设置不应静默覆盖已填的传输目标。
7. 关闭并用脚本重启：外观/字号/配色/目录等仍在，连接密码/密钥仍可用。恢复默认只改草稿，需保存才持久化。
8. “兼容性与未实现”应有不支持项的明确说明，而非能保存却不生效的假开关。托盘/更新/多窗口本轮不动。

## D SFTP/远程编辑
1. 打开密码会话→文件→刷新；右击具体文件，复制路径/重命名/删除必须作用被点的文件，不是之前选中行。
2. 右击空白：新建目录/空文件、刷新、终端cd。新建文件撞名应报错，**不得覆盖原内容**；删除只支持文件、链接、空目录。
3. 右键下载到默认目录，去传输页看任务；默认目录须存在。目录走打包下载，普通文件不能静默覆盖；不安全的服务器文件名应拒绝自动落盘。
4. 文件页“默认上传目录/默认下载位置”只是显式填入；上传仍需给本地/远端完整文件路径。右键上传目前提示使用表单，没有原生picker。
5. 目录中带空格/单引号时“在终端打开此目录”仍正确；带控制字符应拒绝。仅POSIX shell cd。
6. 打开普通文本→改内容→保存；模拟远端修改后保存必须报hash冲突，不静默覆盖。UTF8/8MiB/单文档限制不变。

## E 队列/命令/监控
1. 队列顶部五状态计数、筛选、平均KiB/s/耗时、取消全部、清除已完成。清完成不得清失败或正在传输，失败仍可重试；无total时不显示假的百分比/ETA。
2. 命令库新增`echo [#host]`，参数host填localhost，应显示预览`echo localhost`；执行发往当前会话，追加回车可切换。
3. 参数原样替换，不自动shell转义；参数历史不保存。已有shell的`${HOME}`不是模板。
4. 搜索命令名/组/正文、分组过滤；右击复制文本/编辑/另存副本/删除。删除必须显示具体命令名与不可恢复提示，取消不删。
5. 管理历史：选历史填草稿、单删、确认清空。全部会话执行仍需明确勾选。
6. 监控刷新两次：CPU首帧显示等待；CPU/内存meter、磁盘/网络速率来自本机SSH。点进程表列头排序，按PID/用户/命令过滤；选行填PID，发送信号仍需确认。
7. 网络连接表按端口/IP/PID/进程过滤。暂无历史曲线/网卡选择/详细PID展开，不能据空白声称已实现。
