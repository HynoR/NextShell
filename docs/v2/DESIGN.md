# NextShell 2 界面设计

更新:2026-11-12。取代 `UI-GUIDE.md` / `UI-RESEARCH.md` / `UI-REFRESH-REPORT.md`。

## 原则

1. **终端永远在场。** 文件、监控、命令片段是终端旁边的面板,不是替换终端的页面。
2. **管理类功能收进设置。** 密钥、代理、同步、Agent、导入导出属于偶尔用的功能,放进设置窗口,不占主界面。
3. **直接操作,不填表。** 文件用拖拽、右键和原生选择框,不让用户手工输入本地或远端路径;连接参数默认只露出必填项。
4. **一个入口找到一切。** Cmd+K 命令面板可以连接主机、切换标签、发送命令片段、执行任何操作。
5. **文案写给用户。** 不出现 v1、OSC、keepalive 三态、AAD 之类实现术语;不在常驻位置放警告。

| 区域 | 内容 | mygo 控件 | 开关 |
|---|---|---|---|
| 标题栏 | 隐藏系统标题栏(macOS 红绿灯保留)。会话标签、`+`(新本地终端,长按 / 下拉选主机)、搜索入口(打开命令面板)、设置齿轮 | `TabsBase`、`Button` | — |
| 主机栏 | 收藏、目录树、主机行(状态点、名称、悬停显示 `user@host`)。单击选中、双击或回车连接、右键菜单。顶部 `+` 新建主机,`⌕` 过滤 | `Sidebar` / `Tree`、`SearchField`、`ContextMenu` | Cmd+B,可拖宽 |
| 终端 | 只有终端本身,无工具条 | `terminal.View` | — |
| 右侧面板 | 跟随当前标签的会话。分段切换:文件 / 监控 / 片段 | `Split`、`Segmented` | Cmd+J;Cmd+Shift+F/M/S 直达 |
| 状态栏 | 当前会话连接状态与时长;传输进度(点击弹出传输列表);编码;同步状态;Agent 待批准数(有时才显示) | `Row`、`Popover`、`Progress` | — |

删除:终端上方的「标签名称 / 重命名 / 复制会话 / 重连 / 断开」工具条、底部「工作台」命令栏、右侧 17 个图标的活动栏、标题栏里的快连密码框和外观下拉。

### 无标签时:欢迎页

```
            NextShell
   ┌──────────────────────────────────┐

   └──────────────────────────────────┘
   最近

```

首次启动(没有任何主机)同一页面,最近一栏换成两行引导:「新建主机」和「从 NextShell 1.x 导入连接文件」。

## 标签

- 右键菜单:重命名、复制会话、重新连接、在新窗口打开(M6)、关闭、关闭其他、关闭右侧。
- 断开的会话标签变灰并显示 ⟳,终端内提示「连接已断开 · 按回车重新连接」。
- 双击标签进入行内重命名(`EditableText`)。
- 拖拽排序保留;MRU 切换保留(Ctrl+Tab)。

## 命令面板(Cmd+K)

一个输入框,结果分组:

| 分组 | 例 | 动作 |
|---|---|---|
| 连接 | 输入 `root@10.0.0.5:2222` | 快速连接(密码在随后的认证对话框里输入) |
| 主机 | prod-web-01 | 连接(Cmd+回车:在新标签中打开文件面板) |
| 标签 | db-master | 切换 |
| 命令片段 | 重启 nginx | 发送到当前会话(Option+回车:发送到全部会话,需确认) |
| 操作 | 新建主机、打开设置、切换深浅色、导入连接、本地终端 | 执行 |

控件:`Popover` + `TextInput` + `List`,模糊匹配。

## 对话框

### 主机编辑(新建 / 编辑)

`Dialog`,宽 560,左侧三个分段:

- **常规**:名称、主机、端口、用户名、目录、标签。只有这一段的必填项在首屏。
- **认证**:`Segmented` 选密码 / 密钥 / SSH Agent / 键盘交互;只显示对应字段。密钥从下拉选择,下拉末尾有「导入密钥…」「生成新密钥…」。
- **高级**:代理、字符编码、心跳间隔(默认「跟随全局设置」)、使用 `~/.ssh/known_hosts`、备注。

底部:[取消] [保存] [保存并连接]。编辑已有密码时显示「已保存 · 修改」,点「修改」才出现输入框。

### 主机指纹

- 首次连接:显示主机、算法、SHA256 指纹,按钮 [取消] [信任并连接]。不再要求手打 `TRUST`。
- 指纹变化:红色警告对话框,对比旧 / 新指纹;默认按钮是「断开」,「更新指纹并连接」需要再确认一次。

### 认证提示

密码 / 键盘交互问题在对话框里依次回答,带「记住密码」勾选框。

## 右侧面板

### 文件

```
[文件|监控|片段]
‹ ›  / var / log ▾                 ⬆ 上传  ↻  ⋯
☐ 名称              大小    修改时间
  📁 nginx           —      昨天
  📄 syslog          2.1M   10:42
  📄 auth.log        80K    09:13
```

- 顶部面包屑(`Breadcrumbs`),点击跳转,最后一段可编辑。`⋯` 菜单:新建文件夹、新建文件、显示隐藏文件、跟随终端目录(开关)、打开默认下载目录。
- 表格(`Table`):单击选择、Cmd / Shift 多选、双击进入目录 / 打开文件(远程编辑)。
- 右键:打开、用外部编辑器打开、下载到…、下载到默认目录、复制 / 剪切 / 粘贴、重命名(行内)、删除、复制路径、在终端中 cd 到此处、发送到其他服务器…。
- 拖入(Finder → 表格)上传;从表格拖出到 Finder 下载(mygo 支持时)。上传 / 下载目标都用原生选择框,无路径输入框。
- 目录上传下载自动走打包传输(有 tar 时),用户不用选。

### 传输列表

状态栏点击「⇅」弹出 `Popover`:每项名称、方向、进度条、速度、取消 / 重试;底部「清除已完成」。

### 监控

- 卡片:CPU、内存、网络(↑↓)、磁盘,每张卡片一个数字 + 迷你曲线(`chart`)。
- 下方二级分段:进程 / 网络连接 / 系统信息。进程表可搜索、排序,右键发送信号(需确认)。
- 默认自动刷新(面板可见时),无「刷新」按钮;非 Linux 主机显示「仅支持 Linux 服务器」。

### 命令片段

搜索框 + 分组列表。单击发送到当前会话;带 `[#参数]` 的片段弹出填参对话框;右键:编辑、复制、发送到全部会话、删除。底部「+ 新建片段」。

## 设置窗口

独立窗口(mygo 多窗口),Cmd+, 打开。左侧 `Sidebar` 导航:

| 分类 | 内容 |
|---|---|
| 通用 | 外观(跟随系统 / 浅 / 深)、语言、关闭窗口时确认、启动时恢复标签、默认下载目录、外部编辑器 |
| 终端 | 字体、字号、行高、配色方案(预设 + `ColorWell` 自定义)、光标样式、滚动缓冲、链接点击确认、剪贴板权限 |
| SSH | 默认心跳、已知主机列表(可删除)、本地 Shell |
| 密钥 | 列表 + 导入 / 生成 / 重命名 / 删除,显示被几个主机使用 |
| 代理 | 列表 + 新建 / 编辑 / 删除 |
| 同步 | 登录 / 工作区 / 同步状态 / 冲突处理 |
| Agent | MCP 开关、token、待批准与历史、黑名单、紧急停止 |
| 导入导出 | 导入 NextShell 1.x 连接文件、导入 FinalShell、导出连接 |
| 回收站 | 已删除的主机,恢复 / 永久删除 / 清空 |
| 关于 | 版本、检查更新、日志目录 |

所有修改即时生效、自动保存(去掉「保存设置」按钮);需要重连才生效的项旁边写「新会话生效」。布尔项用 `Switch`。

## 反馈

- 操作结果用 `Toast`(右下角,3 秒),错误 Toast 带「详情」。去掉状态栏里的长文本消息。
- Toast(及其「详情」对话框)出现在发起操作的窗口:远程编辑器窗口里的保存 / 重新载入 / 外部编辑在编辑器窗口,设置窗口里的在设置窗口,其余在主窗口。编辑器窗口已关闭时回到主窗口。
- 危险操作(删除、发送到全部会话、发信号、覆盖文件)用 `AlertDialog`,按钮写具体动作(「删除 3 个文件」),不写「确定」。
- 空状态都有一句说明 + 一个主按钮。

## 快捷键

| 动作 | macOS | Windows / Linux |
|---|---|---|
| 命令面板 | Cmd+K | Ctrl+K |
| 新本地终端 | Cmd+T | Ctrl+Shift+T |
| 关闭标签 | Cmd+W | Ctrl+Shift+W |
| 第 n 个标签 | Cmd+1…9 | Ctrl+1…9(仅终端焦点) |
| 上 / 下一个标签 | Cmd+Shift+[ / ] | Ctrl+PageUp / PageDown |
| 最近使用标签 | Ctrl+Tab | Ctrl+Tab |
| 主机栏 | Cmd+B | Ctrl+Shift+B |
| 右侧面板 | Cmd+J | Ctrl+Shift+J |
| 设置 | Cmd+, | Ctrl+, |
| 复制 / 粘贴(终端) | Cmd+C / V | Ctrl+Shift+C / V |

原则:Windows / Linux 上终端里的裸 Ctrl+字母全部交给 shell;应用快捷键用 Ctrl+Shift 或 Alt。实现统一用 `ui.Cmd`,不手写 `runtime.GOOS` 判断(除上表中 Win / Linux 需要额外 Shift 的项)。

## 视觉

- 沿用 `design.go` 的颜色 token(深色 `#0b1220` 底、青绿强调色),不新增调色板。
- 选中行(表格、侧栏)是 `Accent` 底 + `AccentText` 字,正文对比度 ≥ 4.5:1(浅色 4.8、深色 10;`design_test.go` 检查)。单元格里自己着色的次要文字用 `mutedOnRow`,淡色强调底(`Accent.Alpha(.15)`、`SurfaceHover`)上的强调色文字用 `accentInk`,不要直接用 `TextMuted` / `Accent`。
- 间距 4 的倍数;列表行高 28,面板标题 32,标签栏 36,状态栏 24。
- 边框只用在分区之间;卡片内部不再套卡片。表单不用整页白卡片。
- 图标 16px,沿用项目自有 SVG;状态点:绿 = 已连接、琥珀 = 连接中、灰 = 断开、红 = 失败。
- 终端区域与面板同底色,只用 1px 分隔线,不加圆角边框。

## 代码结构

```
internal/appui/
  app.go          App 外壳:布局、标签、事件分发、对话框栈
  hosts.go        主机栏 + 主机编辑对话框
  tabs.go         标签栏、右键菜单、MRU
  palette.go      命令面板
  welcome.go      欢迎页
  panel_files.go  文件面板 + 传输列表
  panel_monitor.go
  panel_snippets.go
  settings/       设置窗口,每个分类一个文件
  dialogs.go      指纹、认证、确认
  design.go icons.go platform.go(保留)
```

每个功能一个 state struct(`hostsState`、`filesState`…),`App` 只持有它们和会话列表。测试按功能放,使用 `ui.Tester` 并输出明 / 暗截图。
