# NextShell 2 更新日志

## 2.0.0(开发中)

### 新布局

- **标题栏与标签**:标题栏居中是搜索框(`Cmd/Ctrl+K`),右侧是自动批准徽标、同步图标和「服务器」「设置」按钮;标签移到中间列顶部。
- **三栏可折叠**:左栏、右栏、底部工作区都能折叠,折叠状态和尺寸重启后保留。
- **面板搬家**:文件在底部「SFTP」,片段在底部「命令库」,监控概览在左栏「系统监控」,传输在右栏「传输队列」,Agent 状态在右栏「Agent 活动」;原来的底部状态栏和右侧面板已删除。
- **会话卡与标签**:左栏顶部显示连接状态、`user@host:port`(点击复制)、编码和时长,断开后可直接重连;每个标签带主机颜色和连接状态点,断开时也可点击重连。
- **主机列表移到「服务器」**:主窗口不再有主机侧栏。`Cmd/Ctrl+O` 打开「服务器」,`Cmd/Ctrl+B` 折叠左栏,`Cmd/Ctrl+J` 打开底部工作区,`Cmd/Ctrl+Shift+M/S` 打开底部对应的标签;`Cmd/Ctrl+Shift+F` 改为查找终端内容。

### 连接管理与凭据

- **设置里不再有密钥、代理、导入导出**:这些已移到「服务器」窗口,设置里只留入口。
- **「服务器」四页**:连接、密钥、代理、凭据。连接页左边是目录树,中间是主机磁贴,右边是详情和编辑表单。
- **批量操作**:多选主机或右键目录,即可批量绑定密钥、代理或凭据,应用前先预览。磁贴左侧的服务器图标可拖到目录,也可右键「移动到」。
- **内联新建**:编辑主机时可直接新建或生成密钥、新建代理,创建后自动选中;新主机沿用上次的认证方式和密钥。
- **密钥**:同一私钥按指纹只存一份;导入密钥后,主机按指纹或名称自动重新绑定。认证失败时可换用户、认证方式或已有密钥,并写回主机。
- **导入导出**:可把 `.json` 文件拖进窗口导入。导出时主机按引用指向凭据,不把同一份用户名和密码复制进每台主机,导出文件不含明文密码。
- **凭据**:一组用户名加认证方式(密码、密钥、SSH Agent 或键盘交互),可以被多台主机共用。密码存入钥匙串或加密存储。
- **主机选用凭据**:勾选「使用凭据」后,用户名和认证由凭据决定(表单中只读);不勾选则沿用主机自带的认证。改一次凭据的密码,引用它的所有主机都用新密码连接。
- **删除凭据**:删除被引用的凭据前会确认;没有自带用户名的主机会先拿到一份拷贝,其余主机退回自带认证,删除后仍能连接。
- **连接路径**:界面、`Cmd/Ctrl+K`、重连、复制会话和 MCP 连接,都按凭据连接;云同步加密携带凭据。

### 服务器实时状态

- **左栏常驻监控**:连上 Linux 主机后,左栏「系统监控」每 2 秒刷新一次 CPU、内存、网络等状态,不用打开任何东西。
- **每台主机可开关**:编辑主机时可在「终端」分组里开关「监控状态」,默认开启,关闭后不再采样。
- **网卡与图表**:可选择网卡,指标条使用 1.x 的配色,并有网络图;「系统信息」标签显示静态信息和历史曲线。
- **缓存数据**:切回某台主机时立即显示上次的数据并标注「缓存数据」;重连或切换标签后仍在,重启应用后清空。
- **延迟与路由追踪**:左栏 PING 卡显示到服务器的往返延迟(不依赖系统 ping,无需额外权限),监控关闭时显示「—」。点击打开路由追踪抽屉,按 Esc 或关闭按钮收起。找不到 nexttrace 时会提示去「设置 → 网络工具」配置路径。
- **进程与网络**:进程管理器、网络管理器各自作为该主机的标签,从左栏打开;标签跟随主机,关闭标签即停止采样。`Cmd/Ctrl+W` 只关闭当前工具标签,不关会话。
- **连接中**:首次连接时中间区域显示「正在连接…」并出现「连接中」标签;点标签的关闭按钮、按 Esc 或 `Cmd/Ctrl+W` 即可取消连接。未保存的快速连接没有标签,暂不能取消。

### 工作区工具

- **SFTP 目录树**:文件面板左侧是目录树,跟随当前目录展开,只显示真实文件夹(不含指向文件夹的链接);工具栏按钮可以隐藏。
- **命令输入栏**:终端下方可直接输入命令发送到当前会话;历史与「发送命令」共用,最多 100 条,重启后仍在,↑/↓ 翻阅。
- **命令片段**:单击片段会填入命令输入栏,不会直接执行。
- **终端内查找**:`Cmd/Ctrl+Shift+F` 打开查找栏,搜索屏幕和回滚,显示「第 N / 共 M」,Esc 关闭;不再切到 SFTP 标签。
- **Agent 活动**:右栏「Agent 活动」列出最近 10 条调用,待批准的可直接批准或拒绝。「紧急停止」会拒绝待批准的请求、关闭自动批准并中止正在运行的命令,之后可「恢复 Agent」;完整历史在「设置 → Agent」。
- **实时编辑**:右栏「实时编辑」列出正在同步的远程文件,状态为监听中、同步中、已同步、冲突或出错。关闭编辑器不会停止同步;冲突时可选覆盖远端、重新载入或另存本地。未配置编辑器时默认用系统文本编辑器,无需先设置。
- **删除文件夹**:可以删除含有内容的文件夹,确认前先显示将删除的项目数。
- **监视网格**:标签栏最右的网格按钮(或命令面板「显示 / 隐藏监视网格」)把所有会话的终端并排显示成实时、只读的缩略图,每个磁贴带主机颜色、状态点和标题;已断开的会话显示最后一屏并标「已断开」。点磁贴或任一标签进入该会话,Esc 退出;网格里的按键不会发给任何会话。

### 外观与设置

- **主色**:可从六种主色中选择(蓝、青、绿、紫、橙、玫红),默认蓝色与 1.x 相同;换色后所有窗口立即生效。
- **主机颜色**:在主机编辑表单的「标签与备注」里为主机选一种颜色(共八种),以竖条显示在标签和「服务器」磁贴上;改色后已打开的标签立即跟随,选「自动」则按主机自动分配。
- **设置分组**:按 1.x 分为窗口行为、文件传输、远端编辑、终端、网络工具、云同步、回收站、Agent、关于;原来的「SSH」页并入「终端」。
- **默认折叠**:「窗口行为」里可以让左栏、底部工作区每次启动时默认折叠,优先于上次退出时的折叠状态;不勾选则沿用上次的状态。
- **浅色主题状态色**:警告、成功、危险三种状态色加深,白底上的文字更清楚。
- **背景图**:「设置 → 窗口行为 → 外观」可以选一张图片作为主窗口的背景,面板和终端会半透明地透出它,「界面不透明度」(30–80%)调节透出多少。图片会另存一份,之后移动或删除原文件不受影响;不是图片或太大(超过 20 MB 或 2500 万像素)的文件会被拒绝并说明原因。不设背景图时界面和以前完全一样。
- **托盘**:「窗口行为」里新增「最小化到托盘」和「关闭窗口时最小化到托盘」(系统没有托盘时不显示)。开启后窗口收进托盘,连接和终端继续运行;点击托盘图标显示窗口,右键(Linux 点击)菜单有「显示窗口」、最近连接、「新建本地终端」和「退出」。从托盘或 `Cmd/Ctrl+Q` 退出时,仍会在有会话或未保存文件时确认。

### 编辑器与标签

- **内置编辑器标签**:远程文件在主窗口的标签里编辑,未保存时标签上显示圆点;`Cmd/Ctrl+S` 保存。可「在新窗口打开」,新窗口里有「回到主窗口」。关闭有未保存修改的文件时,可选保存、不保存或取消。
- **关闭确认**:关闭已连接的会话标签前会询问,点 ×、中键、`Cmd/Ctrl+W`、命令面板或右键菜单都一样。勾选「不再询问」后不再提示,可在「设置 → 窗口行为」里恢复。
- **「+」菜单**:可以新开本地终端、连接最近用过的主机,或打开「服务器」;`Cmd/Ctrl+T` 仍是本地终端。
- **标签细节**:同一主机的多个标签显示为「名称 (2)」,切换后的标签自动滚入可视区,中键点击即可关闭标签。
- **断开提示**:左栏折叠时,会话断开后终端下方会出现「连接已断开 · 重新连接」一行,回车也能重连。

### 修复

- 批量设置认证不再清空代理,代理默认「保持不变」。
- 导入的私钥主机不再被改成键盘交互认证,保持私钥认证。
- Agent 执行命令时输出被截断,不再在一个字符中间切断(避免乱码)。
- **传输提示**:传输完成或失败时弹出提示,失败的可直接「重试」。
- **连接失败提示**:连接或重连失败时,提示会点名是哪一台主机。
- **密码输入**:取消密码输入时不再弹出错误。
- **指纹确认**:主机指纹改用等宽字体显示,可以选中复制。
- **命令面板**:选择已打开的主机时,优先切到它的标签。
- **快速连接**:输入已保存主机的名称或地址,即可匹配到该主机。
- **监控失败**:无法读取状态的服务器会显示明确的状态,并可点「关闭此服务器的监控」;连续失败三次后不再重试,不再反复报错。
- **服务器表单**:表单底部的按钮始终可见,有未保存的修改时会先确认;键盘可用 Enter、`Cmd/Ctrl+S` 和 Esc。
- **批量移入回收站**:可以撤销这次操作。

## 2.0.0-rc1

NextShell 2 的第一个候选版本(预发布)。

### 这是什么

NextShell 2 是**全新的产品**,用 Go 和原生界面重写(不是 Electron,也不是网页),不是 1.x 的升级版:

- 不读取、不迁移 1.x 的数据库、设备密钥和钥匙串。
- 1.x 用户:先在 1.x 里导出连接文件,再到 2 的「设置 → 导入导出」(或首次启动的欢迎页)导入。
- 2 使用独立的数据目录,不会动 1.x 的数据;预发布版不会出现在 1.x 的更新提示里。

### 亮点

- **原生界面**:不是网页套壳,深浅色可跟随系统。
- **终端为中心**:终端始终在场;文件、监控、命令片段是右侧面板,不会盖住终端。主机栏、多标签,`Cmd/Ctrl+K` 命令面板一个入口找到主机、标签、片段和各种操作。
- **SFTP 文件面板**:面包屑、多选、右键菜单、拖入上传、目录自动打包传输、状态栏传输列表。
- **服务器监控**:CPU、内存、网络、磁盘,进程和网络连接。
- **命令片段**:搜索、一键发送、带参数的模板。
- **远程编辑**:远程文件在独立窗口里编辑、保存回服务器,也可交给外部编辑器。
- **给 AI Agent 用的 MCP 端点**:默认关闭;开启后需要令牌,应用把端口和令牌写入用户配置目录下的 `mcp.json`,配套的 MCP 桥自动读取,不用手工配置。桥不在 npm 上,随本版本以 `nextshell-mcp-0.2.0.tgz` 发布(需要 Node.js 24+)。
- **三级命令策略**:禁止(永不执行)/ 风险(始终手动批准)/ 其余(可自动批准,有时限,重启即关闭)。命令输出自动脱敏。这是防误操作的护栏,不是安全沙箱,只在信任当前 Agent 任务时开启自动批准。
- **不打扰**:每次运行最多提示一次,之后 Agent 在后台标签里干活,不抢焦点、不切标签;你正在输入时它不会往里写。
- **主机指纹**:首次连接需确认,指纹变化直接拒绝并提示。

### 接入 Claude Code

装 Claude Code 插件(`/plugin marketplace add HynoR/NextShell`,`/plugin install nextshell`),或不装插件直接添加:

```sh
claude mcp add nextshell -- npx --allow-remote=root -y https://github.com/HynoR/NextShell/releases/download/v2.0.0-rc1/nextshell-mcp-0.2.0.tgz
```

`--allow-remote=root` 不能省:npm 12 起默认禁止从 URL 安装,这个选项只放行命令行上的这个地址。其他支持 MCP 的客户端同理,命令是 `npx --allow-remote=root -y <上面的地址>`。

### 下载

- macOS(Intel / Apple 芯片通用,12 及以上):`.dmg` 拖进「应用程序」,或 `.zip`。
- Windows(x64 / ARM64):`-setup.exe` 安装到当前用户目录,无需管理员;或 `.zip` 解压即用。
- Linux(x64):`.deb`、`.rpm`(装好后命令是 `nextshell`)、`.tar.gz`。
- `nextshell-mcp-0.2.0.tgz`:给 AI Agent 用的 MCP 桥,见上。
- `SHA256SUMS.txt` 是全部文件的校验值。

### 已知限制

- **未签名**:本版本没有 Apple 开发者签名、公证和 Windows 代码签名。
  - macOS:首次打开请右键 → 打开;或运行 `xattr -dr com.apple.quarantine /Applications/NextShell.app`。
  - Windows:SmartScreen 提示时点「更多信息 → 仍要运行」。
- Linux 需要 GTK 3(主流桌面发行版已自带)。
- 没有自动更新,请到发布页下载新版本。
- 云同步在本版本不可用。
- 暂不支持 OSC 133(Shell 提示符标记),等待上游框架开放相关事件。
- 文件面板暂不支持把文件拖出到 Finder / 资源管理器下载,请用右键「下载到…」;拖入上传可用。
- 监控和打包传输要求远端是 Linux。
- Windows 上的 SSH agent 只支持系统自带的 OpenSSH Agent(需在"可选功能"里安装 OpenSSH 客户端并启动 ssh-agent 服务),暂不支持 Pageant。
- macOS 是主要验证平台;Windows 和 Linux 是第一次发布,未经真机日用,欢迎反馈:默认下载目录、打开文件夹、本地终端(PowerShell)、Agent 登录。
